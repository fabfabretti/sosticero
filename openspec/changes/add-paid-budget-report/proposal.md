# Proposal

## Why

Banca ore shows paid substitution budgets and their detailed register, but its existing PDF only exports weekly availability. Staff need a printable financial report for one sede or both, with the same recognizable presentation as the Statistiche report.

## What Changes

- Add a separate report preview and print/PDF action for paid budget usage and recorded paid hours.
- Allow choosing Centrale, Succursale or both, and apply the choice consistently to summaries and records.
- Preserve the current availability PDF and existing financial accounting rules.

## Capabilities

### New Capabilities

- `paid-budget-reporting`: Preview and print paid budget usage and assignment details for selected sedi.

### Modified Capabilities

None.

## Impact

Banca ore frontend, shared print presentation and frontend verification; existing paid availability and finance response data can provide the report. No accounting or database changes are intended.
